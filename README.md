# Scikit-learn Learning

A collection of educational Jupyter notebooks covering Scikit-learn fundamentals, data preprocessing, feature engineering, machine learning models, and model evaluation in Python.

This repository is designed to build a practical understanding of machine learning workflows using Scikit-learn.

## 📚 Topics Covered

### 1. Scikit-learn Fundamentals
- Introduction to Scikit-learn
- Understanding features (`X`) and target variables (`y`)
- Training models with `fit()`
- Making predictions with `predict()`
- Splitting datasets with `train_test_split()`

### 2. Data Preprocessing
- Handling missing values
- Imputation with `SimpleImputer`
- Feature scaling with `StandardScaler`
- Normalization with `MinMaxScaler`
- Encoding categorical features
- Using `OneHotEncoder` and `OrdinalEncoder`

### 3. Feature Engineering
- Feature selection
- Creating polynomial features with `PolynomialFeatures`
- Transforming numerical features
- Creating new features
- Selecting informative features

### 4. Machine Learning Models
- Linear Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Trees
- Random Forests
- Support Vector Machines (SVM)

### 5. Model Evaluation and Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- Classification Report
- Cross-validation
- Hyperparameter tuning

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/m-ghorbani-dev/scikit-learn-learning.git
```

Navigate to the project directory:

```bash
cd scikit-learn-learning
```

Create a virtual environment:

```bash
python3 -m venv .venv
```

Activate the environment on Linux:

```bash
source .venv/bin/activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Start Jupyter Notebook:

```bash
jupyter notebook
```
